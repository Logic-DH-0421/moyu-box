# 框架架构与第一阶段边界

## 结构

```text
src/Host/          Windows 宿主、项目注册表、生命周期、消息协议
src/Shell/         鱼塘、鱼聊占位、鱼饵、设置；不直接访问磁盘或启动进程
projects/          首次启动默认项目描述文件
adapters/bilibili/ B站项目到本地网页容器的协议适配
vendor/            已有项目的独立源码快照和 WebView2 SDK
examples/          可导入的第六个项目示例
tests/             功能与边界测试
```

宿主通过项目描述文件选择适配器。UI 仅使用统一的请求/响应协议，不根据项目名称执行系统操作。新增网站、本地网页项目和外部 EXE 只增加描述文件/包；复杂后端需实现新的适配器。

## 状态与并发

- 项目状态：`idle → loading → ready / external / error`；关闭后移除会话。
- 页面显示与项目运行分离，离开项目只隐藏 WebView2 控件；本地服务和浏览实例保持。
- 同项目并发打开共享同一个初始化 Task；加载完成后仅当前项目显示，避免迟到页面覆盖当前页面。
- 初始化期间关闭会话会标记取消；未完成的回调不得重新显示已关闭页面。
- 浏览进程失败只将所属项目置为 error；重试关闭该实例后重新启动。
- 退出顺序：关闭网页 → 停止阅读器服务 → 经鉴权请求停止B站适配服务 → 结束宿主。B站服务超时后只结束盒子启动的适配进程；不结束官方客户端或用户外部 EXE。

## 信任边界

- 框架网页只从 `https://shell.moyubox.local` 加载；原生消息检查来源，方法按明确列表分派。
- 普通网页、网站和本地网页项目不暴露 HostObject 或原生消息桥。
- 时节保留特定原生操作，仅允许其固定虚拟主机；备份只写该项目目录。
- B站服务只监听 `127.0.0.1` 随机端口；检查 Host、Origin 和随机令牌；方法白名单，不提供通用执行代理。
- 本地网页包不支持路径越界、符号链接或重解析点；限制 50MB、5000 文件；导入包不能声明内置适配器。
- 外部导航只允许 HTTPS / 本机 HTTP；不自动跳转到 file、javascript、系统协议。
- 外部网页功能需要摄像头、麦克风、定位等授权时，当前阶段默认拒绝；后续可增加按站点权限管理。

参考 Microsoft WebView2 的来源校验、限制 HostObject 和避免通用原生代理的指导：
https://learn.microsoft.com/microsoft-edge/webview2/concepts/security

## 数据设计

- 持久化统一带 schemaVersion，未知版本停止读取，防止静默降级覆盖。
- 框架配置采用临时文件 + 原子替换 + 上一版本备份。异常主文件单独保留；备份也无效时停止启动。
- 用户项目包与运行数据分开，框架配置与项目浏览存储分开。
- 所有内置快照使用新数据目录，不接管原程序的数据与进程。

## 本期不包含

公共聊天室服务、项目市场、自动更新、旧数据自动迁移、跨设备同步、跨项目搜索、全局快捷隐藏键。窗口“隐藏”与托盘恢复已经实现。

## 0.2.0 扩展

壳管理运行期标签顺序、激活页与邻页切换；宿主 SessionManager 继续按项目 ID 维护唯一实例。切换功能只隐藏实例，关标签才释放。收藏与资料属于框架设置，项目不直接访问设置对象。GitHub 作为元数据与运行入口映射，book 复用独立阅读器服务。静态网页外开使用仅监听 127.0.0.1 的只读 HTTP 服务，检查 Host/Origin 和路径边界，停止会话时释放端口；盒内仍使用稳定虚拟域名以保留网页存储。EXE 入口不授予第三方网页进程启动桥接。

## 0.3.0 Word 阅读适配

Word 渲染器由带固定提交和指纹的 MIT 上游模块提供，不授予原生桥接；TXT/EPUB 解析与进度继续使用既有 C# 后端。新增 word-reader 独立入口，book 根据 defaultBookReader 选择展示方式。显示方式与书籍目录分离，已有书籍无需搬迁。浏览器与盒内都由同一 loopback 服务提供资源；资源白名单与原 API 鉴权分开处理。新资源准备脚本可重复生成发行目录，不在构建过程中下载或执行上游安装脚本。

## 0.4.0 窗口与显示策略

WindowLayout 将 Windows 最大化/还原与项目生命周期分离：仅从功能页进入盒内项目触发默认最大化，返回时恢复自动保存的普通窗口；手动还原后的标签切换不强制放大。普通窗口启动尺寸按工作区限制。SessionManager 按项目保存缩放，适合宽度用 WebView2 的实际布局测量并防抖更新，异步测量用请求序号避免覆盖新的手动选择。壳宽度不再被固定 min-width 锁死，原生项目视口继续跟随壳的布局矩形。

## 0.6.0 项目服务隔离

SessionManager 统一管理加载、默认浏览器入口、切换复用、服务异常退出和关闭。阅读器使用独立 MoyuReaderService 进程与动态端口，MultiAI 使用独立 MoyuProjectsService。服务就绪、页面加载、业务操作分别处理，宿主不根据页面成功推断业务成功。服务凭据通过进程环境传入且不记录；项目内容和项目业务日志不转发到本体。

时节原生便签只对用户选择的文档 ID 授权文件保存，采用临时文件校验后替换。浮窗由 WindowLayout 保存和恢复窗口状态。注册表升级补充缺失的内置项目并保留已有用户配置，200 项容量已满时明确提示延后补充。

TikTok 位于 experimental/tiktok，默认项目与构建均不引用草稿。

## 0.7.0 兼容性修复

PackageArchive 为静态 ZIP 提供有界解压与 CRC 校验，ArchiveImport 管理入口选择与暂存清理；文件夹注册失败后撤销本次新建目标。局部资源预检只提示、不补抓网络。ProjectFit 样式只在本地项目适合宽度时注入，固定缩放时撤销。阅读器通过每书 TextLayoutVersion 保持旧书分章/位置不变。TaskbarWindowGroup 为已启动 EXE 的窗口暂存和恢复 AppUserModelID，校验 PID 所有权，不嵌入或结束外部进程。
