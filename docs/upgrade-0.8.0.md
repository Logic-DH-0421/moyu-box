## 榜单内容直接显示

GitHub 今日趋势先实现启动后台读取、来源 HTML 解析、框架内列表展示、手动刷新、加入鱼塘与本地缓存。访问固定 `https://github.com/trending`，不调用榜单 API。不读取登录态、Cookie 或个人浏览记录。

每次读取限时 15 秒、最大解压内容 2MiB、最多显示 25 条；只接受合法 GitHub 仓库链接。空页面、验证页面、来源结构变化不会记录为空榜成功。失败显示提示，已有缓存继续显示并标记为旧数据。缓存写入失败仅降级，不影响软件主功能。

## 问题的技术结论与边界

### Markdown 伪装项目

已搜索但未确定与“各类内容伪装为 Markdown”描述完全一致的仓库。用户也暂未找到名称，因此本轮没有冒用相近项目。SneakRead 是文章阅读外观伪装；Microsoft MarkItDown 是文件转 Markdown，两者都不能直接等同于该描述。待明确仓库后再核实许可证、构建和功能兼容。

### 自动游客身份与鱼聊

自动分配昵称及基础资料可以省去注册、密码找回和第三方登录；真正游客身份仍须由聊天服务器分配用户 ID 并签发凭证。不能把本机随机昵称或 UUID 当作服务器认证。仍需服务端收发、持久化、重连去重、限流、禁言和管理。当前鱼聊没有连接公网聊天服务，本轮未伪造账号或上线状态。

### 下载即用

只更改下载目录不会自动注册项目。不要直接向配置目录或运行目录写入下载内容，应独立使用下载收件目录，再做完成校验、类型识别、受控导入与生成配置。

- TXT / EPUB：下载完成后可复用书籍导入和默认阅读器。
- ZIP / HTML：先安全解包、检查入口，再注册静态项目。
- EXE：注册独立程序入口，不应下载完成就直接执行。
- GitHub 源码 ZIP：不等于成品；需要构建环境或项目适配器。
- Skill：需要 Agent 运行环境及依赖，不能当普通网页执行。

本轮未修改 Windows、外部浏览器或各项目的下载设置，也未添加自动安装/执行功能。
